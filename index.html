데이터 분석

스트링별 모니터링 데이터를 올리면 어느 스트링이 언제부터 얼마나 나빠졌는지 찾아냅니다. 일사량 센서가 없어도 됩니다 — 같은 인버터 안의 정상 스트링을 기준으로 삼아 날씨·계절 영향을 상쇄합니다.

지속 저하 상시 낮은 스트링 계단식 하락 퓨즈·다이오드 고장 점진 열화 PID·오염 누적 시간대 편중 음영·수목 동절기 한정 결함 아닌 것 걸러내기

모니터링 데이터를 여기에 놓으세요

엑셀(.xlsx) 또는 CSV · 스트링별 전류·출력·발전량 데이터

🔒 파일은 서버로 전송되지 않습니다. 모든 계산이 이 브라우저 안에서 끝나며, 페이지를 닫으면 아무것도 남지 않습니다. 발전소 데이터를 외부에 넘기지 않고 확인하실 수 있습니다.

1

컬럼을 알아서 읽습니다

헤더 줄 수, 시간 컬럼 위치, 채널 번호 표기가 장비마다 달라도 데이터를 보고 추론합니다. 미사용 슬롯·복제 채널은 자동으로 제외합니다.

2

정상 스트링을 기준으로 비교

PI = 해당 스트링 발전량 ÷ 같은 인버터 정상 스트링의 중앙값. 평균이 아니라 중앙값을 쓰는 이유는 고장 채널이 기준을 오염시켜 자기 고장을 숨기기 때문입니다.

3

원인과 확인 방법까지

저하의 모양으로 원인을 좁힙니다. 하루 종일 고른 저하는 모듈·접속 결함, 특정 시간대만의 저하는 그림자. 현장에서 무엇을 확인할지 함께 냅니다.
