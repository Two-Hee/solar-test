판정 기준

사용법

1. 실행

압축을 풀고 SOLAR_ANALYZER.html을 Chrome 또는 Edge에서 더블클릭합니다. Python 설치와 인터넷 연결이 필요하지 않습니다.

2. 업로드

.xlsx, .xlsm, .csv 파일을 끌어놓거나 선택합니다. 구형 .xls 파일은 Excel에서 .xlsx로 저장한 후 사용하세요.

3. 자동인식

시간열, 스트링 전류, DC/AC 전압·전류·전력, 주파수, 발전량을 자동으로 인식합니다. 결과가 다르면 열 매핑에서 역할을 수정합니다.

4. 진단 범위

스트링은 동료 채널과 시기·시간대 패턴을 비교합니다. 인버터는 DC 입력 중 AC 정지, 3상 불평형, 전압·주파수 계측 배율, 출력·발전량 불일치를 검사합니다.

5. 제한사항

일사량과 동료 인버터가 없으면 날씨 영향과 설비 손실을 완전히 분리할 수 없습니다. 표시되는 결손값은 상대 비교 또는 전기량 모순에 근거한 점검 후보입니다.

모든 분석은 현재 브라우저 안에서만 수행되며 업로드 파일은 외부로 전송되지 않습니다.
